# Сохранения SillyTavern: «Герой-рационал»

Здесь хранятся данные игры: чаты, персонажи, лорбуки `ГР —`, настройки, расширение «Летопись Эльфридена».
Ключи API (`secrets.json`) сюда не попадают — на новом устройстве их нужно ввести заново.

## Файлы в папке SillyTavern

| Файл | Что делает |
|---|---|
| `Играть.bat` | Загружает свежие сохранения из облака, запускает Таверну, каждые 15 минут сохраняет, при выходе (Ctrl+C в окне) сохраняет и выгружает |
| `Сохранить.bat` | Сохранить сейчас: локальный резерв + выгрузка в облако |
| `Загрузить.bat` | Забрать последнюю версию из облака (Таверна должна быть закрыта) |
| `Подключить облако.bat` | Один раз: вход в GitHub, создание приватного репозитория `eldfrieden-save` |
| `Восстановить резерв.bat` | Вернуть данные из локального zip-резерва |

Локальные резервы (последние 20) лежат в `%USERPROFILE%\SillyTavern-Резерв`.

## Новый ПК

1. Откройте этот репозиторий на GitHub, скачайте файл `_tools/install-new-pc.ps1`.
2. Правой кнопкой по файлу → «Выполнить с помощью PowerShell».
3. Введите логин GitHub. Скрипт сам поставит Node.js, Git, SillyTavern и скачает сохранения.
4. Запустите `Играть.bat` и введите ключ API в Таверне.

## Если облако и ПК разошлись

Скрипты ничего не удаляют. Перед каждой загрузкой делается локальный резерв. Если слияние не удалось, данные ПК остаются как были, а в резервах есть копия.
